# Print and play

- Poker size 63x88 mm (2.5 x 3.5 in). Bridge 57x88 mm, tarot 70x120 mm, mini 44x63 mm.
- Bleed 3 mm (1/8 in) each side; keep text and key art 3 mm inside the trim (safe area).
- 300 DPI: trim 744x1039 px; with bleed 815x1110 px.
- 3x3 poker cards fit Letter and A4 portrait. Print at 100% scale. Print houses (The Game Crafter, MakePlayingCards) want one file per card with bleed and no marks; home printing wants sheets with crop marks.
- Card stock: 250 to 300 gsm, or paper in sleeves with an old card behind.
